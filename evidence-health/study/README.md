# 實證健康與醫學研究判讀：離線學習包

18章、108單元、54張原創中文SVG、108題含情境的學習單與解析、120個中英名詞，以及一份原創合成案例JSON。不需要安裝Python、連接API或提供個人健康資料。

1. 解壓後保留study-pack下study與assets的相對位置。
2. 從[學習單](workbook.md)選單元，點相連SVG，可用瀏覽器放大或列印。
3. 先寫出比較、分母、時間、假設及未知，再開[參考解析](answers.md)。文字可用任何支援Markdown的編輯器閱讀。
4. 查[中英名詞](glossary.csv)與[案例資料](cases.json)，核對輸入是否完整；不要把未知填成0或最佳條件。
5. [來源與版本](sources.md)區分正式文件、草案、網頁更新與存取限制。外部正式工具與論文需另外開啟來源；本包沒有複製它們的題庫或評分表。

這是圖解、案例與練習包，不包含完整網站閱讀器或全部課文。網頁上的9個互動活動在課程HTML及assets中，完整網站可直接開啟index.html離線閱讀；下載本包不會同步網頁筆記與進度。

所有圖與案例為本課原創概念教學，沒有真實個人病歷、產品療效或臨床診斷。數學活動解釋尺度與假設，不產生自動GRADE評級、醫療處方或個人檢測結論。查核2026-11-16，出版年依各來源，不虛構當年新版。
