## 模態支援需要逐項確認

某模型能處理圖片，不代表同一供應商的每個 Embedding、File Search 或 SDK 都接受圖片。查明模型、端點、輸入格式、大小限制與回應定位。模型版本與服務功能是不同層次。

Gemini 官方 Embeddings 目前文件包含多模態方向，但實際使用應確認所選模型與工具支援，不把文字範例 `gemini-embedding-001` 任意改成所有模態。[Gemini Embeddings](https://ai.google.dev/gemini-api/docs/embeddings)

## 文件可有多種表示

文字抽取保留語句，頁面影像保留版面，表格結構保留列欄和單位。可以索引多種表示，再以來源 ID 對回同一頁或區塊。但每種表示需有相容 query 路徑，不是把不同空間混算。

技術文件的答案可能依賴一張表的註腳或圖例。若只把整頁編成一個向量，找到頁面仍不等於找到精確答案。保留 bbox、頁碼和結構化欄位，有助後段查證。

## 音訊的時間單位

選整段錄音、固定秒數、語者分段或語意段落，會影響定位和 context。轉錄文字與原音訊可分別索引，回傳時保存起訖時間和轉錄版本。

若任務是找「提到某個規格的片段」，文字轉錄也許足夠；若要找音樂、音色或非語音事件，需要適合的聲學表示。文本相同不表示音訊任務相同。

## 影片與多重訊號

影片可有影格、動作、音軌、字幕與時間關係。取樣影格會漏掉短暫事件，單純平均多幀向量也可能遺失先後。索引粒度要與使用者問題匹配，並保存時間定位與抽樣策略。

## 共用 Metadata 契約

```json
{
  "asset_id":"demo-video",
  "segment_id":"00:10-00:20",
  "modality":"audio",
  "start_seconds":10,
  "end_seconds":20,
  "encoder_spec":"versioned-fingerprint",
  "source_version":"v1"
}
```

這是自訂教學 schema，不是某個供應商 API 回應。正式服務還要加授權、來源與品質。模型產生的描述若作為索引文字，應標明衍生資料並保留原始媒體。

## 練習與參考答案

**題目：**模型找到整段一小時錄音，使用者要找某句話，是否已完成任務？

**參考答案：**只完成粗定位。需要更細分段、時間索引或轉錄搜尋，並提供可開啟的時間範圍。表示單位過粗會影響實際可用性，即使向量相似度很高。
