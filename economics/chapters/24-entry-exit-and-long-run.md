# 進入、退出與長期均衡

解釋零經濟利潤、正常報酬與競爭調整，不把它們誤讀成沒有收入。

## 零經濟利潤的含義

經濟利潤已扣機會成本，包括自有資本與經營者時間的正常報酬。零不表示會計利潤或薪水為零。自由進入、相同可得技術與其他條件下，正經濟利潤吸引進入，供給增加壓低報酬；負利潤則促使退出。

## 長期條件

對同質廠商與固定投入價格的簡化，P=MC=minATC。例F=100、c=10、d=2，最小ATC的Q=10，ATC=30；單一廠商可在此規模獲零經濟利潤。產業總需求再決定廠商數，整數與容量限制會使精確結果不同。

## 經濟租與異質性

稀缺地點、獨特技術或能力可帶來經濟租。即使自由進入，不同廠商也不必利潤完全相同，因為稀缺投入價格與所有權不同。不能把理想同質廠商圖當成「現實任何持續高利潤都違反經濟學」。

## 調整不是瞬間完成

建廠時間、搜尋、融資與不可逆成本使進出有遲滯。若新進者預期繁榮短暫，未必投資；政策不確定也會改變等待價值。比較靜態的長期均衡不自動提供過渡速度或期間失業。

## 競爭作為基準

完全競爭提供理解福利與價格訊號的基準，不是每個市場的描述。下一章引入市場力量、策略與資訊差異。判斷政策時應先說市場結構，再決定哪一組推導適用，避免在不同模型間偷換假設。

## 零經濟利潤的算術

F=100、c=10、d=2，Q=10時TC=100+100+100=300，P=30帶來收入300。這已包含模型指定的投入成本；若漏掉自有資源機會成本，不能只靠會計表宣稱經濟利潤為零。自由進出是長期條件，企業數、設備與產品品質的調整都需要時間。

```python
q,p=10,30
tc=100+10*q+q*q
print("profit",p*q-tc)
```
