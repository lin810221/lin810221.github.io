# 所得分配、財富、不平等與貧窮

分清所得與財富，讀懂Lorenz、Gini與貧窮指標的資訊和盲點。

## 所得與財富不是同一分布

所得是期間流量，財富是某時點資產減負債。年輕家庭可能當期所得高但淨財富低，退休者則可能相反。比較家庭要說稅前/稅後、移轉前/後、家戶/個人與等值尺度，否則同一數字可能代表不同生活水準。

## Lorenz與Gini

將非負所得由低到高排序，Lorenz畫累積人口比與累積所得比；Gini是與完全平等線間面積的標準化。0表示此測量下平等，越大越不平等。相同Gini可有不同尾部分布；負所得/財富或不同權重的處理需另外定義。

## 虛構算例

四人所得10、20、30、40，Gini=.25；貧窮線25時兩人在下方，貧窮率50%。貧窮缺口平均為[(25−10)/25+(25−20)/25]/4=.2，補充距離資訊。將線設成不同金額會改變結果，應說明絕對或相對標準。

## 不能只看平均或單一比率

平均所得上升可能同時有部分人變差。分位數、所得份額、貧窮深度、流動性與地區生活成本提供不同面向；橫斷面差異也不是同一人一生的差異。政策需要處理工作誘因、保險與機會，不只是把一個指標壓到最低。

## 因果與倫理

教育、財富、家庭與制度互相影響，不能從相關表格立即判責任或公平。再分配政策還需看稅基、行為反應與公共服務效益。清楚區分測量、解釋與價值判斷，能讓分配討論更可檢查。

## 尺度與分布的對照

將每個人所得乘2，Lorenz份額和Gini可不變，但固定貧窮線下更少人落入。若貧窮線是中位數固定比例，相對貧窮結果又不同。因此需要同時報所得水準、線的定義與分布；跨國資料還要處理購買力和家庭規模，不把一個指標排名當完整福利排名。

```python
from microeconomics import distribution
print(distribution((10,20,30,40)))
print(distribution((20,40,60,80)))
```
