# 多模態與文件AI學習包

16章96單元，從來源與座標到OCR、版面、表格、VLM、檢索、評估、安全和DocWeave。此包提供離線複習，完整Python與合成fixture另在課程頁的examples.zip。

## 使用順序

先寫[學習單](worksheet.md)，再看[解析](answers.md)，用[術語表](glossary.md)確認詞義。每題均有對應[中文圖解](../assets/figures/README.md)，請追蹤原點、框、來源頁與驗證邊界，再用自己的話解釋。

## 三次交付

先在同一來源上比較原生文字、掃描與旋轉頁。接著核對表格、4500小計、225稅額與4725總額，以及每個欄位的原文框。最後完成DocWeave，注入指標前故障、重跑、破壞產物並確認拒絕，留下可回查證據。

## 查核與範圍

[來源索引](sources.md)保留官方文件與原始論文，[版本紀錄](versions.json)保留相容環境、模型hash與執行範圍。公式使用本機KaTeX；數量、條件、分母與算例都在對應單元。模型服務、手工矩陣、人工逐字稿與真實OCR各自標示，不混成同一種推論。
