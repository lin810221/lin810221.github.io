# 人體解剖與生理學：圖解與練習包

這份學習包使用原創中文示意圖和紙筆練習，**不需要程式、Python或安裝套件**。網站核心也是閱讀、看圖、操作路徑與口述解釋。

## 如何使用

1. 保留解壓後study-pack內的study與assets資料夾；圖和學習單的相對路徑才能正確。
2. 先讀workbook.md，每章六題，對應120個閱讀單元；先看相連圖，再口述或畫圖作答。
3. 完成後讀answers.md，核對理由、方向、條件和限制。不是只記選項。
4. glossary.csv為中英名詞表，可用試算表或文字編輯器開啟；sources.md整理官方來源與查核範圍。
5. assets/figures內有64個SVG，雙擊即可在支援SVG的瀏覽器放大、另存或列印。圖內包含標題、中文標註、圖說與替代描述。

下載包是圖解與作業材料；完整課文、互動和筆記在課程網頁。網頁保留整個LearningNote資料夾即可離線閱讀，不需本機伺服器。筆記與進度存在目前瀏覽器，不隨下載包同步；重要內容請另備份。

## 圖怎麼讀

先辨人體左右、前後與切面，再找邊界。沿箭頭說物質或訊號的名稱，別把血路、氣道和消化腔接成同一條管。方塊流程不表示器官真實形狀，線圖不表示精密比例；需要真實影像及個人檢查時，使用相應方法和專業。

## 全課練習

20章、120個單元各有一題及理由；另有完整概念圖專題。你可使用虛構生活角色，不需寫個人病史、上傳影像，或做憋氣、過度換氣、刺激疼痛、快速起立及平衡極限測試。

## 來源與原創圖
