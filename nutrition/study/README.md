# 營養學與飲食科學：圖解與讀圖任務

這份補充包有48張中文SVG，對應原課96個單元。每章三張圖，每張可供不同單元閱讀；每個單元的任務各自說明重點。圖解可離線放大，不需要安裝程式。

## 使用方式

1. 解壓後保留study-pack下的study和assets兩個資料夾。
2. 從[讀圖任務](read-tasks.md)找主題，開啟相連SVG，先看構造、邊界、圖例，再追路徑、分母或時間。
3. 先用自己的話回答，再回課程原稿的機制、練習與解答核對。學習包是圖解補充，不包含完整網頁閱讀器或全部課文。
4. 雙擊SVG可在支援的瀏覽器放大和列印；手機網頁中的大圖可橫向捲動，也能另開圖檔。
5. 原有Python範例、資料和測試仍在獨立examples.zip，作為選讀輔助，不需要先寫程式才能理解圖解。

## 範圍與日期

本次圖解補強2026-11-16；原課內容與環境基準日期為2026-11-09，其指南、套件與資料版本仍依各章來源，不因補圖自動變成新指南。圖片為原創概念圖或本學習空間原創解剖圖再用，非醫學影像或精密比例；再用來源在[圖解依據](sources.md)記錄，不複製外站圖片。

既有單元ID、標題、順序及課文保留，筆記與進度使用原本的儲存位置。重要筆記仍請自行備份，下載圖解不會跨裝置同步筆記。圖與虛構案例不提供個人診斷、承重或其他安全認證。
