# 公共衛生與流行病學：離線學習包

20章、120單元、60張原創中文SVG、120份情境學習單與解析、140個中英名詞，以及原創案例JSON。核心練習不需程式或真實健康資料。

1. 解壓後保留study-pack中的study與assets相對位置。
2. 開[學習單](workbook.md)，放大圖、標定義、寫出比較與假設。
3. 核對[解析](answers.md)、[名詞](glossary.csv)與[原創資料](cases.json)。
4. [來源索引](sources.md)列正式版本、資料年、查核日與每張圖的依據；外部來源按其授權和網路可用性存取。

本包包含圖、案例與練習，不包含完整網站閱讀器或所有課文。完整課程資料夾的index.html另有12個可離線使用的互動活動；學習包不會同步瀏覽器筆記或進度。

各案例獨立。人口頻率例、康復的Simpson例、聚餐例、34件虛構監測清單、篩檢期望人數與成本效果不得混用。未知不補成零，沒有風險集合或零分母時保留未定義。

查核2026-11-17。教學模型不產生個人診斷、真實疫情預測或自動政策決策；實務行動需適用的定義、資料、權責與參與。
