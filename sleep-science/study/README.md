# 睡眠科學與晝夜節律：離線學習包

18章、108個單元、54張原創中文SVG、108個含情境學習單與參考解析、120個中英名詞，以及一份原創案例JSON。核心練習不需寫程式、不需API或提供私人睡眠資料。

1. 解壓後保留study-pack內study與assets的相對位置。
2. 開[學習單](workbook.md)，先點圖放大、找時間與路徑，再自己回答問題。
3. 核對[參考解析](answers.md)、[名詞](glossary.csv)及[原創案例資料](cases.json)。未知不能補成0，日誌中WASO與最後醒後的定義不可重扣。
4. 來源、正式版本、存取限制和每張圖的依據見[來源索引](sources.md)。外部專業工具及論文另按原來源存取，本包不重製授權評分內容。

學習包包含圖解、案例與練習，不包含完整網站閱讀器或全部課文。網站的10個互動活動可由完整課程index.html離線使用；本包不會同步網頁中的筆記與進度。

資料都是虛構。架構圖480分鐘／TST440與日誌TST390是不同夜晚；穿戴例200個30秒片段只有100分鐘，不能誤稱整夜。日誌日期按離床所在日標記；睡眠中點採入睡至最後醒來區間的中點，另於案例說明。

簡化 $\frac{S}{C}$ 、一階消退、UTC換算和錯分表只教機制與定義，不校準個人、不產生睡眠限制、光照、用藥、PAP或駕駛安全判定。教材查核2026-11-17，正式出版年依各來源。
