# SQL 與資料工程學習包

18 章、108 個單元，主線從 SQL 走到 DataHarbor 資料交付。此包適合離線複習；可執行 Python、SQL 與 fixture 另在課程頁的 `examples.zip`，不在此學習包內。

## 使用順序

先按 [學習單](worksheet.md) 作答，每題先寫出資料粒度、條件與預期結果，再核對 [解答](answers.md)。不確定名詞時查 [術語表](glossary.md)；需要版本和能力依據時查 [官方來源](sources.md) 與 [版本紀錄](versions.json)。

## 讀圖方式

36 張原創中文圖在 [圖解索引](../assets/figures/README.md)。先自己追蹤一筆資料、圈出提交與發布邊界，再讀圖說。圖中的數量、時間區間與狀態是有意設計的合成案例，不是效能量測或特定雲端服務的承諾。

## 三次交付練習

第一階段用基礎商店資料回答 paid 訂單總額與退款後金額，列出 JOIN 倍增反例。第二階段用 DataHarbor 兩批事件交付 11500 USD cents 的當前快照，說明來源序號與刪除契約。第三階段注入發布中斷，記錄資料庫、游標、outbox 與讀者指標的不同狀態，再恢復並核對筆數、總額和雜湊。

## 公式與條件

教材用本機 KaTeX 排版數學式。讀加權平均、品質比率、重試與新鮮度時，同時說明每個符號的定義與分母為零的情形；百分比與空值不能只看表面數字。SQL 語法、欄位名與 API 使用程式碼字體。
