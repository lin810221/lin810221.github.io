# 執行紀錄與界線

日期：2026-11-23（Asia/Taipei）。版本來源查核與程式實測分開記錄。

## 實際環境

Windows x64，Python3.13.13一般GIL環境，獨立虛擬環境；CPU、float32、1個Torch執行緒。torch2.15.0+cpu、torchvision0.29.2+cpu、NumPy2.5.5、Pillow13.0.0、OpenCV headless5.1.0.95、ONNX1.23.2、ONNX Script0.7.2、ORT1.32.0。完整22個相依套件通過一致性檢查，精確版本見requirements-lock.txt。

NumPy要求Python至少3.12，ORT1.32的Windows wheel當日尚無cp315，因此採3.13相容環境；不把它誤稱為最新Python分支。GPU、其他作業系統與硬體需另行實測。

## 已執行

39項unittest通過，包含全部24個預設入口、半開XYXY與TorchVision IoU一致性、群組互斥、EXIF／alpha、框與mask共同變換、mask類別與ignore、訓練改善及重現、state_dict還原、未訓練及已訓練模型的動態batch ONNX比對，以及三個專題圖片／報告／模型成品。測試封鎖權重下載函式與urllib網路呼叫；沒有外部模型或資料下載。
