把像素集合變成可量測區域，並理解連通性、腐蝕與膨脹如何改變計數與面積。

## 先定義前景集合

二值圖將每個像素分成前景與背景，可用 bool 或 0／255 的 uint8 表示。這裡的 255 只是二值前景編碼，與語意分割 ignore label 的 255 不同。先確認哪一種顏色代表目標；如果把背景當前景，後續面積與連通元件都可能看似能算，卻回答了相反的問題。

連通元件把相鄰的前景像素分成群組。4-連通只看上下左右，8-連通還包括斜對角。兩個只在角上相碰的像素，在 4-連通是兩群，在 8-連通是一群。這不是哪個演算法算錯，而是鄰接定義不同；計數結果必須連同連通性設定報告。

## 從像素群得到框與面積

假設某元件包含 $x=3,\ldots,6$、$y=2,\ldots,4$ 的全部像素，像素面積為 $4\times3=12$。若轉成本課半開 XYXY，框為 `(3,2,7,5)`。從最大像素索引轉邊界時要加 1；這與框面積公式不加 1 並不矛盾，因為前者是在不同表示之間轉換。

元件像素面積不一定等於外接框面積。L 形物件可能只有 7 個前景像素，框內卻有 16 個位置。物體有洞時，輪廓多邊形面積、像素面積與外接框面積也可能不同，做瑕疵量測前需明定想量哪一種。像素面積還不是平方毫米，真實面積需要校正、尺度與透視假設。

## 形態學如何改變集合

結構元素是定義鄰域形狀的 kernel。對前景為白的二值圖，腐蝕要求鄰域更完整才保留中心，通常使前景縮小；膨脹讓鄰近前景擴展。開運算是先腐蝕再膨脹，常用來去掉小亮點；閉運算是先膨脹再腐蝕，可能補小洞或接小縫。

這些操作具有尺度與方向偏好。 $3\times 3$  方形核可能移除只有一個像素寬的真裂縫；細長水平核可能連接水平方向的片段，卻忽略垂直片段。當兩個物體被閉運算接在一起，連通元件數量會減少。因此「清理後比較乾淨」不能當作計數或分割一定更準的證據。

## 一個受控的連通性實驗

以下獨立示意只建立兩個斜對角點。`n` 包含背景那一類，因此計算前景元件數需扣除背景；這個 0 又是連通元件標籤的背景，不是任意任務共同的類別規範。

```python
import numpy as np
import cv2

mask = np.zeros((6,6), dtype=np.uint8)
mask[2,2] = 255
mask[3,3] = 255
n4, labels4, stats4, centers4 = cv2.connectedComponentsWithStats(mask, connectivity=4)
n8, labels8, stats8, centers8 = cv2.connectedComponentsWithStats(mask, connectivity=8)
assert n4-1 == 2
assert n8-1 == 1
```

元件編號是該次影像分析的暫時索引，不保證代表跨影像的同一物體，也不應假設編號永遠按大小排序。若要挑最大元件，應根據統計表的 area 選取；但「最大就是目標」也是待驗證的任務假設，背景雜物可能更大。

## 實際流程應如何設計

從統一解碼的圖開始，選擇合理的顏色或亮度前景規則，接著根據最小目標尺度決定是否形態處理，再算連通元件與尺寸。每一步保留中間圖：原圖、初始 mask、處理後 mask、元件疊圖。當結果不對時，才能區分是二值化錯、物體本來接觸，還是形態核把它們合併。

把參數視為整個演算法的一部分：門檻、核形狀、核大小、iterations、連通性、面積篩選與邊界政策都需要固定。若影像解析度改變，一個  $3\times 3$  核代表的真實尺寸也改變，不能原封不動沿用。對相碰物體，可能需要距離轉換、watershed 或實例模型，單靠元件計數沒有足夠資訊。

## 練習與解析

**題目：** 5 個螺絲經膨脹後只剩 3 個連通元件，是螺絲少了嗎？一個像素點做  $3\times 3$  方核開運算後消失，可以直接稱為雜訊嗎？

**解析：** 膨脹可能把原本分離的物體連接，計數變化是演算法造成的。小點也可能是真瑕疵；只有結合標註、成像解析度與最小關注尺寸，才能決定是否合理移除。先在含已知細線、洞與相鄰物體的合成圖驗證，再看代表性實際資料。
