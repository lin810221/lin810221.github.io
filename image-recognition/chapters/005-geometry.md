## 先把座標系畫出來

一般影像左上為原點，x 向右，y 向下；NumPy 取值卻寫 `image[y,x]`。寬 W、高 H 的影像，合法像素索引是 $x=0,\ldots,W-1$、$y=0,\ldots,H-1$。框可描述連續的像素邊界，右邊界等於 W、下邊界等於 H 仍合法；它們不是可以直接索引的像素位置。

本課偵測框統一為連續、半開區間的 XYXY：`[x1,x2)×[y1,y2)`。要求 `0≤x1<x2≤W` 與 `0≤y1<y2≤H`；面積是 `(x2-x1)(y2-y1)`，不加 1。這個明確約定使裁切與 NumPy 切片容易對照，也避免混用舊式「兩端都是像素索引」的整數框定義。

## 一個可以手算的框

影像寬 100、高 60，框為 `(10,20,30,50)`。它寬 20、高 30，面積 600。若只把影像在 x、y 都放大兩倍，框變為 `(20,40,60,100)`，畫布成為 200×120，面積增加為 2400。面積變四倍不代表物體真實尺寸變大，只是像素座標單位改變。

$$
x'=s_xx+t_x,\qquad y'=s_yy+t_y
$$

先縮放再平移與先平移再縮放通常不同。若先把 $x=10$ 平移 5 再放大 2 倍，結果為 30；若先放大再平移 5，結果為 25。這就是為什麼 letterbox 的縮放比例與 padding 必須一起保存，部署框才能映回原圖。

## 裁切時不能只減原點

將上例影像裁成範圍 `[20,70)×[10,55)`，新寬 50、高 45。框先相對裁切原點平移成 `(-10,10,10,40)`，再與畫布相交，得到 `(0,10,10,40)`，只剩面積 300。可見比例是原框的一半。若物體完全在裁切外，相交後寬或高不為正，應移除該框並同步移除對應的類別與實例遮罩。

分類任務還需問：裁切掉關鍵部位後原標籤是否仍成立？偵測任務則需決定保留可見比例門檻、遮擋政策與空目標處理。幾何正確只是第一步，增強不能製造語意不成立的答案。

## 翻轉：框邊界與像素中心用不同式子

水平翻轉後，框的左右邊界交換為 $x'_1=W-x_2$、$x'_2=W-x_1$。以 W=100 的原框為例，新框是 `(70,20,90,50)`。單一像素索引則是 $x'=W-1-x$。若把 `W-1-x` 套在框邊界，就會產生一個像素的偏差，尤其貼邊框很容易暴露問題。

以下純函式是座標運算示意，假定輸入已通過正面積及畫布界線檢查。

```python
def hflip_xyxy(box, width):
    x1, y1, x2, y2 = box
    return (width-x2, y1, width-x1, y2)

assert hflip_xyxy((10, 20, 30, 50), 100) == (70, 20, 90, 50)
assert hflip_xyxy(hflip_xyxy((10, 20, 30, 50), 100), 100) == (10, 20, 30, 50)
```

旋轉較複雜：把四角轉換後取最小外接軸對齊框會包含原物體之外的區域；它不是精確的旋轉框。若任務需要方向與角度，應另定 rotated box 契約。任意透視變換也可能改變看見的物體比例，不能把所有幾何變換都視為無害。

## 以視覺與不變量雙重檢查

在圖上疊框、標出原點與角點，再做可逆操作測試。水平翻兩次應回到原框；縮放兩倍再縮回理想上應接近原值；完全貼邊框不應超出畫布。浮點運算使用容許誤差，裁切或取整本來會遺失資訊，不能要求它們完全可逆。

## 練習與解析

**題目：** 寬 80 的影像，框 `(0,5,20,25)` 翻轉後是哪一個？若變成 `(59,5,79,25)` 問題何在？

**解析：** 正確是 `(60,5,80,25)`。錯誤結果把像素索引翻轉規則套到半開邊界，讓貼右邊的目標向左偏移。另請手算裁切原點、縮放與 padding 的組合，並把正向和反向映射都寫進推論輸出契約。
