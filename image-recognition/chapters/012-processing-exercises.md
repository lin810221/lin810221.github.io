用手算、反例與比較實驗，驗收色彩、縮放、濾波、邊緣及連通元件流程。

## 練習不以圖像漂亮為標準

前處理的目標是保留任務需要的訊號並維持資料契約。每題先寫會變與不應變的量，再執行小型驗證。例如 resize 可以改變像素數，但不應產生不存在的 mask 類別；平均可以降低局部極端值，但不保證保存細線。答案必須包含條件，不能只說某方法通常比較好。

這組題目故意使用常數圖、色塊、單點及簡單矩形，因為它們的預期值能手算。真實照片適合後續檢驗效能，卻可能讓錯誤被複雜紋理遮住。先把基本運算驗證清楚，再把同一流程套到未見情境。

## 題目一：灰階與色彩訊息

一個 RGB 像素是 `(200,20,20)`，若示範式採 $Y'=0.299R'+0.587G'+0.114B'$，灰階約多少？把資料轉灰階後再複製三通道，是否能讓模型重新取得紅綠差別？

**解析：** $59.8+11.74+2.28=73.82$，轉成 8-bit 時約為 74，具體取整依實作。複製三份只改輸入形狀，不會找回丟失的顏色訊息。若類別的差別依靠色相，應保留色彩並檢驗相機及照明變化。該公式描述編碼值的灰階近似，不能拿來不加條件地量測物理亮度。

## 題目二：等比例補邊

原圖  $160\times 80$  要放入  $96\times 96$ ，框為 `(20,10,100,60)`。計算縮放比例、新尺寸、對稱 padding 與新框；若模型在新圖預測 `(12,30,60,60)`，如何回到原圖？

**解析：** 比例 0.6，縮成  $96\times 48$ ，上下各補 24；新框為 `(12,30,60,60)`。反向去掉 y padding，再除以 0.6，得到原框。此處尺寸恰好整數，沒有取整差異；一般情況需保存實際新寬高與每邊 padding。若直接把新框乘 $\frac{160}{96}$，y 方向會把補邊一起放大，得到錯誤位置。

## 題目三：mask 的插值

某 mask 只有左右兩類，ID 分別為 0 與 2。放大後邊界出現 ID 1，是模型發現了第三類嗎？若只在最後 `round()`，是否已修好？

**解析：** 它可能是雙線性插值把 0 與 2 混成 1，原標籤沒有第三類；最後四捨五入仍可能保留 1，並不能保證回到合法集合。硬標籤採最近鄰，變換後檢查 unique ID 是否屬合法集合，加上專門的 ignore 值。若研究的是軟標籤，需另定連續 target、loss 與評估，不應與硬 mask 混用。

## 題目四：邊界與平均

所有像素均為 90 的影像，以  $3\times 3$  平均核計算左上角。補零時答案多少？複製邊界時呢？若平均核沒除以 9，內部輸出又是多少？

**解析：** 補零只有四個有效像素，結果 $\frac{360}{9}=40$；複製邊界維持 90。未正規化 kernel 則內部輸出 $9\times90=810$，若存 uint8 可能飽和，掩蓋真正計算結果。不要只根據輸出「看起來仍是白色」判斷正確，應用浮點數值檢核及已知輸入確認。

## 題目五：邊緣與元件

暗亮暗條帶的 x 梯度應含哪些符號？把邊緣圖的連通元件數量當作物體數，會有哪些失敗情境？

**解析：** 暗到亮可為正、亮到暗可為負；直接丟負值會漏一邊。邊緣可能斷裂，一個物體分成多元件；兩物體可能因陰影或相碰而連接；紋理會新增邊緣。邊緣線不是填滿區域，更沒有直接提供個體身分，需要適合的區域處理、額外假設或實例模型。

## 題目六：連通性與尺度

兩個前景像素只在角落相碰，4-連通與 8-連通各幾群？同一個  $3\times 3$  核可否在解析度加倍後視為完全相同的實際處理？

**解析：** 分別為兩群與一群。解析度加倍後，同樣像素核在物理場景中覆蓋較小範圍；若目的依毫米尺度清除小物，應先校正或根據比例調整，再驗證邊界效應。不能只把 kernel 大小機械式加倍就宣稱結果等價，因為離散化及形狀也可能改變。

## 整合挑戰：建立可反駁的比較

建立含圓、細線、椒鹽點與接近邊界矩形的合成圖，另外產生不同曝光與解析度版本。比較「無前處理、平滑、閾值加開運算」三條流程，預先列出對小目標、面積及計數的期待。保留所有中間圖和參數；如果某流程去掉噪點同時漏掉細裂紋，要把兩種效果一起呈現。

進入真實資料後，從訓練／驗證集選參數，測試集留待最後；不挑最漂亮的單張圖作為唯一證據。最終結果至少包含失敗圖、目標尺寸及照明分組，讓「有效」的主張有明確適用範圍。
