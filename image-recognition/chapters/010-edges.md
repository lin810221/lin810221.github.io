用有正負號的差分量測局部變化，再區分邊緣偵測、區域閾值與物件答案。

## 邊緣描述變化，不描述物件名稱

影像梯度表示某方向上強度變化的速度。從暗處跨到亮處，差分可為正；反方向則為負。物體邊界可能產生梯度，陰影、反光、印刷紋理也可能產生梯度。因此「找到很多線」與「辨識出物體」之間仍有資料與語意問題，不能直接畫上等號。

把一列灰階值寫成 `[10,10,90,90]`，相鄰差分是 `[0,80,0]`；反過來則出現 -80。若用無符號 8-bit 保存這些差分，負值可能被截掉或在不恰當的陣列運算中繞回，造成錯誤結論。先用 float32 或帶符號型別保留計算值，展示時才另外映射到可見範圍。

## 方向與幅值回答不同問題

Sobel 使用局部平滑與差分，分別估計水平及垂直變化 `Gx`、`Gy`。方向與幅值可用以下形式描述：

$$
M=\sqrt{G_x^2+G_y^2},\qquad \theta=\operatorname{atan2}(G_y,G_x)
$$

`Gx` 大通常表示沿 x 方向強度快速改變，常對應看起來垂直的邊界；不要把「x 微分」誤解為只找水平線。若只取絕對值，會失去明暗轉換方向；若任務只需邊緣強度，這種資訊移除可能是刻意選擇。

## 先用簡單圖檢查符號

以下獨立 API 示意產生暗亮暗的垂直帶。輸出 `gx` 應同時含正負值，`strength` 則非負。此處不把展示用強度取代原始梯度。

```python
import numpy as np
import cv2

x = np.zeros((16,24), dtype=np.float32)
x[:,8:16] = 100
gx = cv2.Sobel(x, cv2.CV_32F, 1, 0, ksize=3)
gy = cv2.Sobel(x, cv2.CV_32F, 0, 1, ksize=3)
strength = np.hypot(gx,gy)
assert gx.max() > 0 and gx.min() < 0
assert np.isclose(gy[3:-3].max(), 0)
```

實際幅值還受 kernel 大小與 scale 影響；不能跨設定直接比較同一門檻。若輸入範圍從 0–255 改為 0–1，梯度數值也跟著縮放。部署時固定前處理與參數，才有可比較的門檻意義。

## 閾值分區與 Canny 有何不同

區域閾值可寫成「像素值大於 T 為前景」，根據的是局部亮度，不直接考慮物體邊界。Otsu 依灰階直方圖選擇分割門檻，適合的分布條件仍要檢查；照明漸變、兩類亮度重疊或前景極少時，不保證找到有用區域。自適應門檻改看鄰域，但也可能把紋理變成大量假目標。

Canny 則經平滑、梯度、非極大值抑制與雙門檻連結等步驟，目的是形成較細的邊緣。低門檻與高門檻不是兩個類別的機率；弱邊緣是否保留還取決於與強邊緣的連接。邊緣圖通常是稀疏線條，不能直接當作填滿的物件 mask。

## 如何選參數而不偷看測試集

先在訓練／開發資料檢查噪音程度、目標尺寸與照明，建立有限的 kernel、門檻比較。驗證集決定選擇後凍結參數，測試集只做最後估計。每張圖如果根據人工目視調到最漂亮再報結果，量到的是人工介入後的流程，應明確說明，不能宣稱是固定演算法自動效能。

錯誤分析可分成真邊界漏掉、紋理誤檢、陰影誤檢與邊界斷裂。這種分類比單純數「多少邊緣像素」更有用。若輸出是送給後續模型，還應比較原圖與增加邊緣資訊是否真的改善未見資料結果。

## 練習與解析

**題目：** 將 `[100,20]` 做前後差分得到 -80，為什麼直接把負數設 0 會漏掉一側邊界？兩張圖一張較暗，固定亮度門檻是否仍公平？

**解析：** 暗到亮與亮到暗都是變化，丟負值會偏向一種轉換方向；可保留符號，或在目的需要時取幅值。固定門檻受曝光分布影響，需以部署條件驗證；改成自適應門檻也不是自動公平，仍需檢查分組錯誤與資訊是否充分。
