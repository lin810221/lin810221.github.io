## 從一個標籤變成一張標籤地圖

影像分類問整張圖是什麼，偵測問物件在哪個矩形，分割則問每個位置屬於什麼。語意分割的答案可以是一張H×W整數地圖：0代表背景、1代表葉片、2代表花朵。這些數字是類別ID，沒有「2比1多一倍」的量測意義，也不是把彩色照片直接丟進loss。

同一張圖若有三片葉子，語意分割可把它們都標1，不需要知道哪片是第一片；實例分割則需把三片分開。先問你要的是覆蓋面積、物件數量、個別輪廓，還是連續追蹤，才知道要收集哪種標註。框標註較快，但無法直接給出精細邊界；遮罩標註較精細，也要付出品質檢查成本。

## 多類別互斥輸出的形狀

若每個像素恰屬一類，模型常輸出`logits [N,C,H,W]`，target是`long [N,H,W]`。C是類別數，包括本課語意分割的背景類0；這與偵測器把0保留給內部背景的target規則要分清。推論時在channel維度取argmax，得到每個像素的類別，不是沿著寬度取最大值。

```python
import torch

logits = torch.tensor([[[[2., -1.]], [[0., 3.]], [[-2., 1.]]]])
prediction = logits.argmax(dim=1)
assert logits.shape == (1, 3, 1, 2)
assert prediction.tolist() == [[[0, 1]]]
```

第一個像素選類0，第二個選類1。模型還未softmax也能取相同argmax；訓練交叉熵通常直接吃logits，以避免重複softmax及數值不穩定。若需要機率圖，再依正確維度softmax，但它是否可靠仍需校準與評估。

## 二元與多標籤不是同一個類別地圖

二元分割可以用一個logit加sigmoid，target為同形狀0/1浮點值，搭配BCEWithLogitsLoss；也可用兩個互斥類別logits加交叉熵。兩條路都合理，但資料形狀、機率轉換、threshold與loss要一致。不要把單一logit送進多類別argmax，因為只有一個channel，結果永遠是0。

若每個像素允許同時有多種標籤，例如材質與損傷各自獨立，則可用多個sigmoid channel。這與葉片／花朵互斥分類不同；同一位置能否同屬兩類，必須由任務定義，而不是由想用哪個loss決定。

## 解析度與遮罩的物理意義

模型輸出可能比原圖小。將logits插值回需要的尺寸，再argmax，是常見策略；將已變成類別ID的mask放大則須使用保留離散類別的插值政策。兩者不能混用：對類別ID做平滑會創造不存在的中間類別，而對logits做插值仍是在連續分數空間。

像素數比例也不等同真實面積。手機透視照片中，遠處一平方公分可能只占少量像素；若要測量真實尺寸，需標尺、標定與幾何假設。分割模型準確不代表測量流程已校準。醫療或安全場景還需要對應用途的專業驗證，本課圖形算例只驗證方法。

## 練習與解析

一張100×100圖只有100個前景像素。模型全部輸出背景，pixel accuracy是多少？答案是9900/10000=99%，但前景召回為0。這說明大量背景可以掩蓋目標失敗，應同時看前景IoU／Dice、各類表現及固定疊圖。

再問：若兩片互相接觸的葉子都標1，能不能直接用連通元件數當葉片數？不能保證。相接物件可能合成一個連通區，分離物件也可能因孔洞或雜訊變成多塊；要可靠計數，應評估實例辨識或更明確的幾何後處理。
